# PocketSmart AI 🤖

PocketSmart AI is an AI-powered assistant built using Flask and Google Gemini API.

## Features

- 🤖 AI-powered answers using Gemini
- 💬 Interactive chat interface
- 🧹 Clear chat functionality
- 📱 Responsive web interface
- 🚀 Deployed online using Render

## Tech Stack

- Python
- Flask
- Google Gemini API
- HTML
- CSS
- JavaScript
- Gunicorn
- Render
